# Сайт «Астра»

Готовый статический сайт для публикации через GitHub Pages.

1. Загрузите содержимое этой папки в корень репозитория.
2. Откройте Settings → Pages.
3. В Source выберите Deploy from a branch.
4. Выберите ветку main и папку /(root), затем нажмите Save.

Главный файл сайта — `index.html`.
